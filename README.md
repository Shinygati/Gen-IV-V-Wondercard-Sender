## ESP32-S3 Firmware Installation

You can install the **Gen IV/V Wondercard Sender** firmware directly onto your ESP32-S3 using our browser-based installer.

### [Install ESP32-S3 Firmware](https://Shinygati.github.io/Gen-IV-V-Wondercard-Sender/)

**Requirements:**
- ESP32-S3 development board
- USB data cable
- Google Chrome or Microsoft Edge on a computer

**Installation:**

1. Connect your ESP32-S3 to your computer.
2. Open the firmware installer using the link above.
3. Click **Install Firmware**.
4. Select your ESP32-S3 USB device.
5. Follow the instructions to complete installation.
6. Open the Android app, scan for **Gen IV/V Wondercard Sender**, and connect.

The installer supports ESP32-S3 boards only.
